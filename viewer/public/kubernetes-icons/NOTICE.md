# Kubernetes Icons Set

Source: https://github.com/kubernetes/community/tree/main/icons/svg (branch `main`,
retrieved 2026-08-25). These are the `labeled` variants, flattened one level into
`control-plane/`, `infrastructure/` and `resources/`.

The manifest `public/kubernetes-icons.json` is generated from this directory.
